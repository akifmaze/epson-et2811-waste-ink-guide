# Security and privacy reports

This is a documentation repository with no hosted service or automatic reset executable.

For a documentation error that could cause unintended printer writes, open an issue describing the affected section and model without identifiers or raw logs. If the report includes a credential, private device information, or a security exploit, do not place it in a public issue.

Use GitHub's private vulnerability reporting feature if it is available on this repository. If it is unavailable, open a minimal issue asking for a private reporting channel without disclosing the sensitive content. No private contact address is published here.

If a credential has already been exposed, revoke it through its provider; deleting a file alone does not remove it from Git history or existing copies. Report a discovered personal-data exposure without reposting the data.

For physical hardware precautions, read [SAFETY.md](SAFETY.md).
